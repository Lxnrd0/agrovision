AGROVISION / TERRANOVA — ENTREGA FINAL

1. Instala Node.js 24.x.
2. Abre esta carpeta en VS Code y su terminal.
3. Ejecuta: npm ci
4. Ejecuta: npm run verify
5. Si todo termina correctamente, ejecuta: npm run dev
6. Abre http://localhost:3000

Sin Supabase, pulsa «Continuar solo en este dispositivo».
Para IA real o cuenta en la nube, configura .env.local siguiendo README.md y .env.example.

CONFIGURACIÓN DE LA COMPARATIVA DE EQUIPO
- Confirma que Supabase ya tiene agrovision_records y agrovision_members.
- Ejecuta supabase/comparativa-equipo.sql si las funciones/tablas de comparativa aún no están instaladas.
- En supabase/activar-admin-comparativa.sql reemplaza PON_AQUI_TU_CORREO por el correo de la cuenta administradora y ejecuta el bloque.
- Nunca subas .env.local ni claves privadas al repositorio.
- El administrador ve la vista previa, la tabla de promedios y puede publicar el resumen agregado.
- Los integrantes ven solo la última publicación; no pueden publicar ni consultar informes individuales de otros.

Lee ENTREGA_FINAL.md e INFORME_AUDITORIA.md para el alcance y los límites verificados.
No borres los datos del navegador sin descargar primero un respaldo JSON.
