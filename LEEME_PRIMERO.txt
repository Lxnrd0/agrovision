AGROVISION / TERRANOVA — VERSION 1.2.1

1. Instala Node.js 24.x.
2. Abre esta carpeta en VS Code y su terminal.
3. Ejecuta: npm ci
4. Ejecuta: npm run verify
5. Si todo termina correctamente, ejecuta: npm run dev
6. Abre http://localhost:3000

MODO LOCAL E IA
- Sin Supabase, pulsa «Continuar solo en este dispositivo».
- Para análisis IA en modo local, configura ANALYSIS_ACCESS_TOKEN con un secreto aleatorio de al menos 32 caracteres.
- Para modo nube, configura NEXT_PUBLIC_SUPABASE_URL y NEXT_PUBLIC_SUPABASE_ANON_KEY.
- No subas .env.local ni claves privadas al repositorio.

CONFIGURACION DE SUPABASE Y COMPARATIVA
1. Revisa README.md y docs/GUIA_MIGRACION_SUPABASE_1.2.1.md.
2. Haz un respaldo de base de datos y Storage antes de migrar.
3. Ejecuta personal-account.sql (instalación nueva) o revisa actualizar_base_existente.sql (base existente).
4. Ejecuta hardening-1.2.1.sql en una instancia de pruebas.
5. Ejecuta comparativa-equipo.sql.
6. Completa activar-admin-comparativa.sql con el correo de la cuenta administradora.
7. Completa registrar-integrante.sql para cada cuenta autorizada.

La membresía ahora es explícita: conocer el identificador del proyecto no basta para acceder. No elimines membresías ni registros sin revisar primero a qué cuenta y proyecto pertenecen.

LEE
- README.md: instalación y configuración.
- ENTREGA_FINAL.md: resumen de cambios.
- QA_FINAL.md y QA_STATUS.md: pruebas realizadas y pendientes.
- docs/OBJETIVO_Y_OBSERVACIONES_1.2.1.md: objetivo y observaciones técnicas.
- docs/GUIA_MIGRACION_SUPABASE_1.2.1.md: migración segura.
- docs/PLAN_LIBERACION_1.2.1.md: despliegue y reversión.

No integres a main ni despliegues en producción hasta que npm run verify pase con Node 24 y las migraciones hayan sido probadas con dos cuentas en Supabase de pruebas.
No borres los datos del navegador sin descargar primero un respaldo JSON.
